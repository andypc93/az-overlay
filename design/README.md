# Design canvas

Mockups of the settings window pages and the overlay, drawn from the app's real
theme values (`settings_ui.py` THEMES + stylesheet, `config.json` colors).

- `gen.py` regenerates the artboards (`*.dc.html`) and `canvas.json`.
- Published canvas (Claude Design preview): https://claude.ai/code/artifact/ebc6757e-d557-4664-ab60-22a45fb189b7
